# 可靠性修复与发布检查

本轮修改在本地实现和验证，不代表已部署，也不代表私有 COS、百度识图或真实 AI 服务已验收。

## 已补齐的链路

- AI 应用使用服务端独立尝试凭据，图片更新、任务 `APPLIED`、旧文件清理登记共享数据库事务；COS 上传仍在事务外。进程中断后，过期 `APPLYING` 转为 `APPLY_UNKNOWN`。
- `POST /picture/out_painting/recover` 重新校验任务归属、当前编辑权限、源图、有效期。新协议的未提交应用可恢复已有结果；带生成回执的 `UNKNOWN` 只读取和校验原结果，绝不重新生成。过期尝试和旧 token 不能提交。
- 无回执、结果过期、源图已变化以及无新协议凭据的历史不确定任务，仍需人工核对。记录及额度历史不删除。前端本地跟踪过期后不永久锁死，并明确提示新任务可能再次计费。
- 前端轮询覆盖 `APPLYING`；恢复、查询、预览和应用使用登录 Cookie。查询到 `APPLIED` 后重新读取图片，避免只更新任务文字而保留旧图。
- 公共文件在任何上传写入前先登记 `public_file_cleanup`。保存新图时在同一事务内认领凭据；替换、删除、草稿清理同时登记旧文件清理。失败退避上限一小时，不因重试次数耗尽而丢任务；服务重启后继续。清理前检查存活引用，数据库故障不会当作无引用。
- 公共与私有文件的认领均要求尚未进入删除重试；删除可能已在云端完成但响应丢失，因此重试延后不能使过期上传凭据重新有效。
- 通用 `/picture/process` 输出改为服务端生成的独立临时目录，拒绝路径穿越、任意输出路径及额外输出规则。结果提供 `expiresAt`，标称可用 23 小时，未认领文件在 24 小时后进入回收。返回地址不是永久保存承诺，需要长期保存时须走正式图片上传链路。
- `/picture/capabilities` 只返回配置开关，不返回桶名或密钥；前端禁用未配置的私有上传、替换和外部搜图，直接输入上传地址也不能绕过。配置可用不等于真实云服务健康，后端鉴权和存储校验仍然保留。

## 数据库与发布

1. 确认目标库并完成备份。在已具有 AI 任务表的数据库执行 `backend/sql/alter_ai_apply_recovery.sql`，以及 `backend/sql/alter_public_file_cleanup.sql`。两份都是增量、可重复执行脚本；不重建或删除历史任务。更早的 AI 表先核对 `alter_ai_qwen_migration.sql`。
2. 暂停写入并停止全部旧版本实例，等待在途任务结束或保留不确定记录待人工核对，再启用新版本。旧实例不能绕过新凭据继续保存，否则无法依赖原子提交保证。
3. 缺少清理表时新上传登记会失败，不能为恢复上传而去掉登记或改回内存队列。旧版本已经遗失的清理任务无法凭空恢复；历史孤儿文件须另做只读盘点，禁止无差别扫桶删除。
4. 迁移不删除新字段或清理表。回滚代码前停止写入；不得让旧版本继续产生不遵守新协议的应用任务。
5. 核对新建、替换、删除、重启后的清理任务，以及上传失败保留旧图、数据库失败不误删文件。重点监控 `public_file_cleanup` 的数量、最早待执行时间和重试次数。

## 仍需真实验收

- 私有 COS：独立私有桶、正确权限和凭据；匿名不能读取原图、展示图和缩略图；拥有者可读写、未授权成员被拒绝，团队成员撤权后失效。不能复用公共桶或放宽 ACL 伪装修复。
- AI：在明确授权的测试额度内跑完整“创建、后台生成、预览、应用、刷新”链路并核对费用。本地模拟不证明模型效果、真实结果域名、云端计费或生产网络可用。
- 外部搜图：真实第三方返回合法结果前保持关闭；界面禁用不是对失效上游的修复。
- MySQL 专有行为：本地 H2 和隔离 Redis 回归不能代替目标 MySQL 版本上的迁移、当前读及 JSON_TABLE 验证。
