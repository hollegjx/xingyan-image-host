# 第三轮投稿与列表接口

- `POST /picture/submit/public`：`pictureId` 必填；可选 `category` 最长64字符，未传沿用原图，空字符串为未分类。复制成功返回新副本ID，副本仍待审核，原图不变。
- `POST /picture/submission/withdraw` / `POST /picture/submission/delete`：仅接受 `pictureId`，身份取当前会话。仅投稿人本人、公共作品、上传完成且审核状态0允许操作；站点管理员和其他团队管理员不能代替投稿人调用。撤回保留文件且状态变为3；删除仅删除副本并登记既有异步文件清理。原空间、原图及其额度不变。与审核共用图片行锁，失败不改变记录。
- 状态3表示已撤回，不出现在公开图库，不能直接被管理员审核。可进入编辑页修改并重新提交，沿用现有提交规则：普通投稿人进入审核，管理员编辑公共作品会自动通过；页面按身份明确提示。
- `GET /picture/tag_category`：从未删除、公开、上传完成且审核通过的图片中提取实际使用的分类和标签，去空白/重复并排序；不返回私有、草稿、未审核、拒绝或撤回作品的词条。
- `POST /picture/list/page/review`：管理员专用，只有显式 `allReviewStatuses:true` 才查询全部审核状态；未传仍默认0。始终只查询公共且上传完成的作品。仅此接口填充 `reviewerName` 显示名，不新增审核账号信息。
- 公开列表忽略管理员的全部状态参数，继续强制审核通过，并将该参数清除后构造缓存键。

没有新增表或字段。审核状态整数扩展为3；回滚前需核对是否出现非测试的已撤回作品。旧版本不认识该状态，若有真实已撤回数据，不应将其改为审核中或公开；保留数据，回滚版本需保留已撤回不可审核的保护补丁。发布验收只操作本次登记的测试ID，不批量调整真实记录。

发布前准备独立回滚包：从 `f084bd2` 导出源码，应用 `docs/round3-rollback-guard.patch`，执行完整 `mvn verify`，将产物放在本次 release 的 `rollback-safe` 子目录。该补丁仅在旧版审核方法保留行锁与状态3拒绝检查，带真实数据库集成测试。回滚统一使用此包和旧前端，不修改任何撤回记录，也不覆盖旧 release。原始 `f084bd2` 包仍保留，但不可直接用于已有撤回数据的回退。
