# 登录限流运行说明

2026-10-29 生产部署采用以下配置：

```yaml
security:
  login:
    account-max-failures: 5
    ip-max-failures: 100
    window-seconds: 900
```

当前请求经中转机转发，源站未配置该中转机为可信代理，IP 维度实际共用中转地址。因此 100 次阈值是全站失败请求熔断，不是每个真实访客独立的 IP 配额。账号维度仍保持 15 分钟内 5 次失败限制；提高共享 IP 阈值不会放宽账号阈值。

本次只读 SSH 核验中转机时认证被拒绝，无法确认它是否覆盖写入 `X-Forwarded-For`。按运维授权采用上述兜底，没有修改 Caddy 信任配置，也没有把客户端自报的转发头作为可信来源。

后续恢复真实 IP 限流前，必须先确认中转机覆盖客户端提供的转发头；再只信任已核验的中转地址，验证 Caddy 配置后重载，并检查同机其他站点。验收须证明不同真实来源分别计数，且伪造转发头不能改变计数归属。未完成这些验证前，不能宣称已实现按真实 IP 隔离限流。
