# 第三轮 F4：公开直链强制下载调查

核验日期：2026-11-01。未改桶配置、已有对象或业务数据。

## 证据

实际公共展示图与两个独立测试对象均返回 HTTP 200、Content-Type=image/webp、Content-Disposition=attachment、x-cos-force-download=true。两个对象内容相同，分别不设 Content-Disposition 与上传时设置 inline；地域域名与全球加速域名结果一致。加速域名另测浏览器导航请求头，结果仍相同。两对象均已按精确 key 删除（204），签名 GET 复核404。

腾讯云官方《COS 存储桶域名使用安全管理通知（2024年1月施行）》明确：2024-01-01之后创建的桶，默认域名（含存储桶、静态网站、全球加速域名）访问任意文件均不支持预览，服务增加上述两个响应头。浏览器已读取正文，最近更新时间2024-12-03。官方地址：https://cloud.tencent.com/document/product/436/96243

因此本次下载行为是COS域名策略，不能用图片MIME设置或inline元数据绕过。上轮普通请求曾未出现下载头，此次重新实测已经出现，以本次事实为准，不沿用旧结论。

## 方案及授权边界

| 方案 | 改桶配置 | 费用 | 批量改已有对象 | 结论 |
|---|---|---|---|---|
| 新上传补正确Content-Type/inline | 否 | 无新增服务；现有PUT计费不变 | 否 | 无法解除默认域名强制下载，本轮不以无效改动宣称修复 |
| 公开链接改全球加速域名 | 若未启用则需开启；本桶已启用 | 加速流量额外计费 | 无需改对象内容；存量URL可能需迁移/运行时映射 | 实测仍强制下载，不建议 |
| 已备案自定义源站域名及HTTPS | 是，绑定域名及证书、DNS解析 | 常规COS请求/下行费用；域名/证书视现有资源；无强制CDN服务 | 无需改对象；应用URL可做受限运行时域名映射，存量数据库不必批量改 | 官方支持方案，需用户授权与域名信息 |
| 自定义CDN域名 | 是，且需CDN配置 | CDN服务与回源费用 | 无需改对象；需应用链接映射 | 适合另有分发需求时评估，本轮不启用 |
| 本站代理公开展示图 | 不改桶，需代码及服务容量方案 | 占用源站带宽/请求资源、COS下行费用 | 否 | 额外服务器负载，须用户决定后设计，不在本轮自行扩展 |
